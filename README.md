В редакторе: **F1** · **Space K** · **Space hk**

## Быстрый старт

```bash
brew install lazydocker mongosh
# в venv проекта:
pip install ipython debugpy pytest
rustup component add rust-analyzer
```

Открой `nvim` — LazyVim доустановит плагины.  
Python venv: в `.py` файле нажми `Space cv`.
